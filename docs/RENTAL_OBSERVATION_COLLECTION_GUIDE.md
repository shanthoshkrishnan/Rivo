# RIVO — Rental Observation Collection Guide

> **Phase 10 — Data Acquisition for Rent Intelligence**
> Team CLAIRES | ST1010 | PS-11-S3 | Chennai Pilot

---

## Purpose

RIVO's rent ML model (Phase 9) is built and tested, but remains in
`NOT_READY_INSUFFICIENT_DATA` state because the system contains **0 real
rental observations**.

This guide explains how to collect genuine, model-eligible observations
so RIVO can eventually train its LightGBM quantile regression model.

---

## What Counts as a Real Observation?

A real observation is a **verified rent price for a specific property at a
specific point in time**, collected from a consenting source.

### ✅ Acceptable sources

| Source type | Example | Freshness label |
|---|---|---|
| Owner interview (in person or phone) | Owner of flat in Velachery confirms ₹18,000/mo | `LIVE` |
| Tenant interview | Occupant confirms current rent paid | `LIVE` |
| Authorised rental portal snapshot | Licensed/permitted data from NoBroker, MagicBricks API (with authorisation) | `LIVE` |
| Public property registry record | Tamil Nadu registration deed rent clause | `HISTORICAL` |
| RIVO Direct listing (owner submitted) | Owner fills RIVO Direct form with consent | `LIVE` |
| Field agent survey | RIVO agent visits locality and records rents from hoardings/boards | `LIVE` |

### ❌ Never acceptable

| What | Why |
|---|---|
| Demo seed listings (88 CMRL-anchored samples) | Clearly labelled DEMO; fabricated |
| Synthetic data generated by scripts | `is_synthetic=True` — never model-eligible |
| Online asking rents scraped without authorisation | Violates terms of service |
| AI-generated plausible rents | Fabrication |
| Copying from property news articles without primary source | Unverified |

## Model Eligibility Gate

The ML pipeline enforces these thresholds **before** training:

| Metric | Minimum required | Current status |
|---|---|---|
| Real observations | 50 | 0 |
| Unique property IDs | 30 | 0 |
| Unique localities | 5 | 0 |
| BHK classes (1/2/3...) | 3 | 0 |
| Independent sources | 2 | 0 |
| Temporal span | 7 days | 0 days |

Check current eligibility at any time:

```bash
GET /api/v1/rentals/eligibility
GET /api/v1/rentals/admin/data-quality
```

## Method 1: RIVO Direct (Preferred for ongoing intake)

Owner or agent submits a listing directly via the RIVO platform.

### API

```http
POST /api/v1/rentals/direct
Content-Type: application/json

{
  "locality": "Velachery",
  "address": "7, 3rd Cross Street, Velachery",
  "latitude": 12.9816,
  "longitude": 80.2180,
  "rent_monthly": 18000,
  "maintenance_monthly": 500,
  "deposit": 54000,
  "bhk": 2,
  "area_sqft": 900,
  "furnishing": "semi-furnished",
  "property_type": "flat",
  "availability_status": "AVAILABLE",
  "consent_to_publish": true
}
```

Accepted listings are immediately eligible for model training.

### Update rent (PATCH — records new observation)

```http
PATCH /api/v1/rentals/direct/{listing_id}
Content-Type: application/json

{
  "rent_monthly": 20000,
  "availability_status": "AVAILABLE"
}
```

Every PATCH that changes tracked fields appends a new observation.
History is never overwritten.

## Method 2: Admin Observation Collect (Field Agents)

Use this for observations that don't come with a formal listing
(e.g., rent boards spotted during field survey, phone interviews).

### API

```http
POST /api/v1/rentals/admin/collect
Content-Type: application/json

{
  "listing_id": "FIELD-VEL-2025-001",
  "locality": "Velachery",
  "bhk": 2,
  "rent_monthly": 19000,
  "source": "field_agent",
  "latitude": 12.9816,
  "longitude": 80.2180,
  "area_sqft": 950,
  "furnishing": "semi-furnished",
  "property_type": "flat",
  "availability_status": "AVAILABLE",
  "notes": "Rent board on main road, confirmed with watchman"
}
```

### Response includes

```json
{
  "accepted": true,
  "listing_id": "FIELD-VEL-2025-001",
  "observation_id": "...",
  "eligible_for_model": true,
  "total_eligible_observations": 1,
  "model_eligibility_status": "NOT_READY_INSUFFICIENT_DATA",
  "message": "Observation accepted. 49 more needed for model training."
}
```

## Method 3: Bulk CSV/JSON Import

For importing batched observations collected offline (surveys, spreadsheets).

### CSV format

```csv
listing_id,locality,bhk,rent_monthly,observed_at,source,area_sqft,furnishing,property_type,availability_status
FIELD-ADY-001,Adyar,2,22000,2025-09-01T10:00:00+05:30,field_agent,950,semi-furnished,flat,AVAILABLE
FIELD-ADY-002,Adyar,3,32000,2025-09-01T10:30:00+05:30,field_agent,1200,unfurnished,flat,AVAILABLE
FIELD-VEL-001,Velachery,2,18000,2025-09-01T11:00:00+05:30,owner_interview,900,semi-furnished,flat,AVAILABLE
```

> **`is_synthetic` and `is_demo` must be `false` or omitted.**
> Rows with either flag set to `true` are rejected automatically.

### Import commands

```bash
# Preview without writing (dry run):
python -m scripts.import_rental_observations data/field_survey.csv --dry-run

# Import:
python -m scripts.import_rental_observations data/field_survey.csv

# Import + show data quality report:
python -m scripts.import_rental_observations data/field_survey.csv --report

# Strict mode (exit non-zero if any rows rejected — useful for CI):
python -m scripts.import_rental_observations data/field_survey.csv --strict

# Filter by source:
python -m scripts.import_rental_observations data/mixed.csv --source-filter owner_interview
```

### JSON format (array)

```json
[
  {
    "listing_id": "FIELD-ADY-001",
    "locality": "Adyar",
    "bhk": 2,
    "rent_monthly": 22000,
    "observed_at": "2025-09-01T10:00:00+05:30",
    "source": "field_agent",
    "area_sqft": 950,
    "availability_status": "AVAILABLE"
  }
]
```

### NDJSON / JSON Lines format

One JSON object per line (no surrounding array):

```
{"listing_id":"FIELD-001","locality":"Adyar","bhk":2,"rent_monthly":22000,"observed_at":"2025-09-01T00:00:00Z","source":"owner_interview"}
{"listing_id":"FIELD-002","locality":"Velachery","bhk":3,"rent_monthly":31000,"observed_at":"2025-09-05T00:00:00Z","source":"field_agent"}
```

## Privacy & Consent Rules

- **Never store personal information** (names, phone numbers, national IDs).
- `listing_id` may be any non-identifying string (street code, survey ID).
- Consent to publish is required for RIVO Direct listings (`consent_to_publish: true`).
- Admin/field observations do not require explicit owner consent
  but must be based on publicly observable facts (rent boards, advertised prices).
- **Do not store child names or unnecessary family data.**

## Geocode Confidence

RIVO validates coordinates against the Chennai pilot bounding box:
- Latitude: 12.75 – 13.35
- Longitude: 80.00 – 80.35

`geocode_confidence` is set automatically:
- `HIGH` — coordinates provided directly by owner or verified agent
- `MEDIUM` — locality centroid used as fallback
- `LOW` — rough guess from locality name only

Observations with `geocode_confidence=LOW` are still model-eligible
but contribute lower weight to spatial surface estimation.

## Reaching the 50-Observation Threshold

To reach model eligibility, RIVO needs:

1. **50 real observations** across
2. **30+ unique properties** in
3. **5+ localities** covering
4. **3+ BHK classes** from
5. **2+ independent sources** spanning
6. **7+ days** of temporal data

### Suggested collection plan

| Week | Target | Method |
|---|---|---|
| 1 | 15 obs, 3 localities, 2 sources | Field survey (Velachery, Adyar, T. Nagar) |
| 2 | 20 more obs, +2 localities | Owner interviews (Mylapore, Anna Nagar) |
| 3 | 15 more obs, verify all 50 | RIVO Direct submissions + re-check prices |

After collecting 50+ eligible observations, run:

```bash
python -m scripts.train_rent_model
```

The eligibility gate will confirm readiness before any training begins.

## Troubleshooting

| Problem | Check |
|---|---|
| `is_synthetic=True` rejection | Remove flag or set to `false` |
| `is_demo=True` rejection | These are demo listings; create a new real observation |
| Coordinates outside Chennai | Verify lat 12.75–13.35, lon 80.00–80.35 |
| `observed_at` parse error | Use ISO-8601 with timezone: `2025-09-01T10:00:00+05:30` |
| BHK out of range | Must be 0–10 |
| Rent <= 0 or > ₹10,00,000 | Check for typos in rent |
